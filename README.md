# Matrix Chain Multiplication with Catalan Number Analysis

This C++ program computes the average number of scalar multiplications needed 
to multiply a chain of matrices, using recursive evaluation and Catalan numbers.

## Files
- `matrix_chain.cpp`: The full C++ implementation
- (Optional) `COSC 3320 HW 2 Q3.pdf`: Original write-up and explanation

## Description
The algorithm uses:
- Recursion to evaluate all parenthesizations
- Catalan numbers to count valid groupings
- Average work is computed over all combinations

It calculates the expected scalar operations for multiple matrix sets and outputs results to the console.
